# Java Core → Mastery (0 to Core Java)

This repo is my **topic‑wise deep‑notes + practical exercises** for Core Java, from basics to JVM, memory, and multithreading.

## Topics covered

- 01 Fundamentals
- 02 Deep OOP
- 03 Exceptions
- 04 Collections
- 05 Generics
- 06 Functional Programming / Lambdas
- 07 Streams
- 08 Multithreading
- 09 JVM & Memory
- 10 Reflection
- 11 IO & NIO basics
- 12 Design Patterns (light)
- 13 Testing (JUnit + Mockito intro)
- 14 Mini projects

## How to use

- Each folder has:
  - `notes.md` → deep but concise notes.
  - `exercises/` → Java code you can run and modify.
- Start from `01_fundamentals` and move sequentially.

## Running code

```bash
javac exercises/*.java
java exercises.StudentGradeAnalyzer
```

(Adapt `main` class as needed.)
